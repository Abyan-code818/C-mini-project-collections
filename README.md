# C Project Collection

A collection of simple C programming projects combined into one interactive command-line application.

This project was created as part of my learning journey in C programming to practice fundamental programming concepts and improve my problem-solving skills.

## Features

This application contains four mini projects:

### 1. Multifunction Calculator
A simple calculator with two operating modes:

- **Basic Calculator**
  - Addition (+)
  - Subtraction (-)
  - Multiplication (*)
  - Division (/)

- **Sequential Calculator**
  - Perform multiple mathematical operations in sequence.
  - Continue calculations using the previous result.

### 2. Rock Paper Scissors Game

A simple Rock Paper Scissors game where you compete against the computer.

Features:
- Random computer choices.
- Win, lose, and draw detection.
- Score tracking.
- Multiple rounds of gameplay.

### 3. Student Grade Management System

A simple program to manage and calculate student grades.

Features:
- Input student names, student IDs (NIM), and scores.
- Automatic grade assignment (A, B, C, D, E).
- Calculate total and average scores.
- Display the highest and lowest scores.
- Count passed and failed students.
- Display student records.

### 4. Expense Tracker Application

A basic expense tracking application with a budget management system.

Features:
- Set an initial budget.
- Add expense records and descriptions.
- View expense history.
- Calculate total expenses.
- Display remaining budget.
- Add additional budget.

## How to Run

### Requirements

- A C compiler (GCC recommended).
- A terminal or code editor such as Visual Studio Code.

### Compilation

Compile the source code using GCC:

```bash
gcc main.c -o c_project
```

### Run the Program

**Windows:**

```bash
c_project.exe
```

**Linux / macOS:**

```bash
./c_project
```
