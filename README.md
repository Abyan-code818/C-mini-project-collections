# C Storage

Selamat datang di C Storage!

Repository ini merupakan tempat penyimpanan kumpulan mini project yang saya kembangkan menggunakan bahasa pemrograman C.

## Tentang Repository

Repository ini dibuat sebagai bagian dari perjalanan belajar saya dalam memahami konsep dasar hingga konsep lanjutan dalam pemrograman menggunakan bahasa C.

Setiap mini project dikembangkan untuk melatih kemampuan berpikir logis, memahami algoritma, serta meningkatkan keterampilan dalam mengimplementasikan berbagai konsep pemrograman ke dalam sebuah program.

Seiring bertambahnya pengetahuan dan pengalaman, repository ini akan terus diperbarui dengan berbagai project baru.

## Konsep yang Dipelajari

Beberapa konsep pemrograman yang diterapkan dalam repository ini meliputi:

- Variabel dan Tipe Data
- Input dan Output
- Operator
- Percabangan
- Perulangan
- Fungsi
- Array dan Array Multidimensi
- Pointer
- String
- Structure dan Union
- Algoritma Pencarian
- Manajemen Memori

## Teknologi yang Digunakan

- **Bahasa Pemrograman:** C
- **Compiler:** GCC
- **Code Editor:** Visual Studio Code
- **Version Control:** Git dan GitHub

## Tujuan Repository

- Memperkuat pemahaman terhadap dasar-dasar pemrograman C.
- Memahami cara kerja algoritma dan struktur data.
- Melatih kemampuan berpikir logis dan pemecahan masalah.
- Mengembangkan keterampilan dalam mengimplementasikan konsep pemrograman.
- Mendokumentasikan perkembangan proses belajar pemrograman.
- Membangun portofolio project sebagai bekal pengembangan kemampuan di bidang teknologi.

## Penulis

Repository ini dibuat dan dikelola secara mandiri sebagai bagian dari perjalanan belajar dan pengembangan kemampuan pemrograman saya.
